# Goodness Okechukwu — Portfolio

Personal portfolio for Goodness Okechukwu, Social Media & Content Strategist.

Plain HTML, CSS and JavaScript — no build step. Open `index.html` in a browser to preview.

- `index.html` — all page content (edit text here)
- `styles.css` — design and brand colours (see the `:root` block at the top)
- `script.js` — menu, animations and the contact form
- `assets/` — portrait, favicon and social-share image

Brand palette: Deep Royal Purple `#34014e`, Rich Purple `#540175`, Soft Lavender `#efd0ff`, Signature Yellow `#fcea04`.

The contact form uses [FormSubmit](https://formsubmit.co). The first submission sends a one-time activation email to the inbox set in `script.js`; click the link in it to start receiving inquiries.
